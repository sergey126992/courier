# Демонстрационные данные

Набор `Database\Seeders\DemoSeeder`: учётные записи всех ролей, зоны, двадцать заказов во всех статусах. Правила — [ЧТЗ - Полировка и демонстрация](<../.github/docs/Техническое задание/Полировка и демонстрация/ЧТЗ - Полировка и демонстрация.md>), решения — [ADR-0013](adr/ADR-0013-демо-данные.md).

## Как получить набор

```sh
make up        # собрать и поднять окружение
make fresh     # migrate:fresh --seed: схема и демонстрационные данные
make demo      # таблица учётных записей и ключевые номера
```

Состав задаётся в `config/demo.php`: учётные записи, зоны, число заказов и статусы заказов. Пароль всех записей — `DEMO_PASSWORD` (по умолчанию `password`), почта подтверждена.

Повторный `php artisan db:seed` не создаёт дубликатов: записи находятся по естественным ключам (почта, код зоны, номер заказа) и обновляются; полное пересоздание — `migrate:fresh`.

## Зоны

Зона `msk-demo` создаётся `GeographyDemoSeeder` со справочником из двадцати двух адресов (два вне зоны). `DemoSeeder` добавляет семь зон вокруг: `msk-north`, `msk-south`, `msk-east`, `msk-west`, `msk-center`, `msk-outside-a`, `msk-outside-b`; `msk-demo` они не перекрывают, поэтому выбор зоны по адресу однозначен.

## Заказы

Двадцать заказов с номерами `CRG-<год>-D0001…D0020` и кодами `trk_demo00000001…20`:

| Статус | Сколько | Что видно в интерфейсе |
|---|---|---|
| `created` | 3 | очередь диспетчера: заказы без курьера |
| `assigned` | 2 | назначение ждёт ответа курьера |
| `accepted` | 2 | курьер принял, ещё не забрал |
| `picked_up` | 2 | посылка в пути, есть геоточки |
| `delivered` | 5 | вручено, история заполнена |
| `closed` | 2 | закрытые заказы в отчёте |
| `cancelled` | 3 | отмена до забора, `cancelled_at` заполнен |
| `failed` | 1 | неудачная попытка с причиной |

История статусов повторяет путь переходов домена и заканчивается текущим. Заказы с курьером получают назначение с метками этапов; у заказов в работе — три геоточки пути.

Смены открыты для пяти курьеров; у `courier4@courier.test` смена закрыта — видно, что смена и назначение живут отдельно.

## Отчёт и даты

Даты строятся от начала месяца, поэтому отчёт M8 за период по умолчанию ненулевой в любой день. При `Carbon::setTestNow` номера, коды, суммы и даты совпадают между прогонами (`tests/Feature/Demo/DemoSeederTest.php`).

## Ограничения

- Набор создаётся только в окружениях из `DEMO_SEED_ENVIRONMENTS` (`local`, `testing`); иначе сидер завершается ошибкой до записи.
- Сидер не публикует события, не отправляет уведомления и не создаёт `outbox_messages`/`notifications`: работа идёт с `WithoutModelEvents`.
- Данные обезличены: имена вида «Отправитель Демо 2», адреса — только из демонстрационного справочника.
- Двух активных назначений у курьера нет: ограничение базы соблюдено составом плана заказов.
